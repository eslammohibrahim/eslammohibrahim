## Hi, I'm Eslam

CS student in Giza, Egypt, graduating in 2027. I mostly write Python and I'm into machine learning, especially NLP and anything to do with Arabic.

### Projects

- [Arabic RAG Assistant](https://github.com/eslammohibrahim/arabic-rag-assistant): ask a question in Arabic, it finds the right Wikipedia paragraphs and a small local model answers with sources. Adding retrieval took answer F1 from 0.11 to 0.50.
- [Telco Customer Churn](https://github.com/eslammohibrahim/telco-churn): predicts which customers will leave and works out who is worth a retention offer. Sending offers by expected value beat the usual 0.5 cutoff ($57k vs $37k on test data), with SHAP reasons for each customer and a Streamlit dashboard.
- [Satellite Land-Use Classifier](https://github.com/eslammohibrahim/satellite-land-use-classifier): ResNet18 fine-tuned on EuroSAT, 98.1% on the test set, served with FastAPI. It fell apart on noisy images (15%) until I retrained it with noise (91.5%).
- [Arabic Sentiment Analysis](https://github.com/eslammohibrahim/arabic-sentiment-analysis): positive / mixed / negative for Arabic reviews, 69.2% on 20k test reviews.
- [California House Price Prediction](https://github.com/eslammohibrahim/california-housing): my first one, regression with scikit-learn, R² 0.818.
