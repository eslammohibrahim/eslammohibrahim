### Projects
**[Arabic RAG Assistant](https://github.com/eslammohibrahim/arabic-rag-assistant)**: answers Arabic questions from Wikipedia with sources, using hybrid BM25 + embedding search and a local LLM (qwen2.5 via Ollama). Retrieval lifts answer F1 from 0.11 to 0.50; evaluated with a manual review.

**[Satellite Land-Use Classifier](https://github.com/eslammohibrahim/satellite-land-use-classifier)**: PyTorch image classifier served with FastAPI. ResNet18 transfer learning reaches 98.1% test accuracy; a robustness study found the model failing under noise (15%) and fixed it (91.5%).

**[Arabic Sentiment Analysis](https://github.com/eslammohibrahim/arabic-sentiment-analysis)**: classifies Arabic reviews as positive, mixed, or negative. Arabic text normalization, five NLP models compared fairly, 69.2% accuracy on 20k test reviews.

**[California House Price Prediction](https://github.com/eslammohibrahim/california-housing)**: data cleaning, feature engineering, and a comparison of three regression models. Best model: Gradient Boosting, R² 0.818.
